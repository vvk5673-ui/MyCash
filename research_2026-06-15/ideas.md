# Идеи для MyCash из анализа конкурентов

**Дата:** 15 июня 2026
**Что это:** глубокий разбор 3 ключевых конкурентов (Adesk, ФинТабло, Дзен-мани) + список идей для MyCash и таблица со ссылками на приложения всех конкурентов.

База — исследование марта 2026 (`E:/Arhiv/projects/MyCash_archive/competitors.md`).

---

## 1. Adesk — adesk.ru
Позиционируют себя как «первый сервис финучёта с ИИ-агентом». Самый технологичный конкурент.

**Что есть:**
- 6 отчётов: ДДС, Прибыли и убытки, Баланс, Капитализация, Анализ расходов, Управление долгами
- Платёжный календарь — предупреждает о кассовых разрывах заранее
- ИИ-агент — отвечает на вопросы по финансам словами
- Правила автоматизации — операция сама раскладывается по статьям
- Мобильные приложения (iOS/Android) + боты в Telegram и Max
- Бюджетирование с план-факт анализом

**Подсмотреть:**
- Платёжный календарь / прогноз кассового разрыва
- Правила автоматизации статей
- ИИ-вопросы по финансам (на будущее)

---

## 2. ФинТабло — fintablo.ru
От бренда «Нескучные финансы». Ставка на гибкие дашборды и наглядность. 1800+ компаний.

**Что есть:**
- Сводка с ключевыми показателями + ДДС, ОПиУ, баланс, рентабельность
- Гибкая настройка дашборда — порядок блоков, фильтры, период без перезагрузки
- Быстрая загрузка на больших объёмах
- Графики и визуализация
- Модульность (можно только ДДС)
- Автоподгрузка банковских операций

**Подсмотреть:**
- Настраиваемый главный экран (выбор блоков)
- Фильтры/период без перезагрузки (важно для Mini App)
- Простые наглядные графики «куда уходят деньги»

---

## 3. Дзен-мани — zenmoney.ru
Не совсем про бизнес, но лучший UX ввода операций на рынке.

**Что есть:**
- Автозагрузка операций из 200+ банков (читают SMS и push)
- Автокатегоризация по картам, наличным, инвестициям, крипте
- Виджеты на главный экран телефона
- Бюджеты и финансовые цели
- iOS / Android / веб — единый аккаунт
- Личное и бизнес в одном аккаунте (как наши «Направления»)

**Подсмотреть:**
- Автокатегоризация (запоминать статью по контрагенту/назначению)
- Скорость ввода (минимум тапов)
- Бюджеты/цели по статьям

## Итоговый список идей для MyCash (по приоритету)

| Идея | Откуда | Польза | Статус у нас |
|------|--------|--------|--------------|
| Платёжный календарь / прогноз кассового разрыва | Adesk | ИП заранее видит «когда не хватит денег» | нет |
| Автоподстановка статьи (по контрагенту/назначению) | Дзен-мани, Adesk | Ускоряет ввод даже без голоса | нет |
| Настраиваемый главный экран + фильтр периода без перезагрузки | ФинТабло | Каждый видит важное ему | частично |
| Простые графики «куда уходят деньги» / динамика по месяцам | ФинТабло, Adesk | Наглядность без таблиц | нет |
| Бюджеты/лимиты по статьям | Дзен-мани | «Не трать на рекламу больше N» | нет |
| Ещё более быстрый ввод операции (минимум тапов) | Дзен-мани | Наша ключевая боль | есть, можно ускорить |
| Голосовой ввод + AI-вопросы по финансам | нет ни у кого | Наше УТП | отложено на Этап 3+ |

**Вывод:** конкуренты сильны в прогнозах (кассовый разрыв), наглядности (дашборды/графики) и скорости ввода (автокатегоризация). Три направления, где MyCash может стать лучше, не превращаясь в «комбайн».
