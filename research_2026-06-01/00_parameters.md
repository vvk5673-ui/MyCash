# Параметры исследования рынка финансового учёта

**Дата старта:** 2026-06-01
**Проект:** MyCash (контекст), но исследование общерыночное
**Заказчик:** Виктор Коротков

---

## Согласованные параметры

| Параметр | Значение |
|----------|----------|
| **География** | РФ + СНГ (Беларусь, Казахстан, Узбекистан, Армения, Грузия) |
| **Сегменты** | Физлица (личные финансы) + Малый бизнес/ИП (до 50 млн ₽/год) |
| **Язык** | Полная русификация: интерфейс + поддержка + документация на русском |
| **Активность** | Только активные на июнь 2026 (живой сайт, работающее приложение, продают тарифы) |
| **Дата данных** | Цены/тарифы/фичи — на июнь 2026 (самое свежее); выручка/MRR — последние доступные |
| **Цель** | Общее понимание рынка, без привязки к MyCash |
| **Охват в финале** | 15-20 решений (после слияния) |

## Какие категории включаем

- ✅ Мобильные приложения iOS/Android
- ✅ Веб-сервисы и SaaS
- ✅ Telegram Mini App
- ✅ Telegram-боты учёта

## Какие категории НЕ включаем

- ❌ Онлайн-бухгалтерии (Контур.Эльба, Моё Дело, 1С:БизнесСтарт)
- ❌ Встроенные сервисы банков (Тинькофф Бизнес, СберБизнес, Альфа-Бизнес, Модульбанк)
- ❌ Шаблоны Excel/Google Sheets без отдельного продукта
- ❌ Сервисы для среднего и крупного бизнеса (оборот > 50 млн ₽/год)
- ❌ Чистые финансовые планировщики без учёта операций

## Разделение работы

- **Perplexity** — ширина: максимальный охват, найти всех значимых игроков
- **Claude (через research-агента)** — глубина: по каждому из 15 опорных лидеров копать отзывы, юнит-экономику, инсайты

## Очерёдность

1. ✅ Согласованы параметры и опорный список
2. ⏳ Виктор копирует `01_prompt_perplexity.md` → запускает в Perplexity → приносит результат как `10_perplexity_result.md`
3. ⏳ Claude видит результат Perplexity → запускает research-агента по `02_prompt_claude.md` → сохраняет как `20_claude_result.md`
4. ⏳ Claude объединяет оба исследования в финальную Google-таблицу с 25 колонками

## Финальный формат

**Google Sheets** с колонками (25):

1. Название
2. Сегмент (физлица / бизнес / оба)
3. Страна
4. Год запуска
5. Платформы (iOS, Android, Веб, TG Mini App, TG-бот)
6. Целевая аудитория
7. Все тарифы (название + цена)
8. Бесплатный тариф (есть/нет, лимиты)
9. Минимальная цена ₽/мес
10. Максимальная цена ₽/мес
11. Бизнес-модель
12. Ключевые функции
13. Уникальные фичи
14. Число клиентов
15. Выручка / MRR
16. Рейтинг App Store
17. Рейтинг Google Play
18. Интеграции (банки, 1С, CRM)
19. Голосовой ввод (да/нет)
20. OCR чеков (да/нет)
21. Оффлайн режим (да/нет)
22. Синхронизация устройств (да/нет)
23. Сильные стороны
24. Слабые стороны
25. Инвесторы / раунды
