Варианты иконки для Telegram

Все варианты — на основе нового бренда (волна + ₽, золото→графит) с синим акцентом на ₽ (цвет кнопки «Открыть» в Telegram), 512×512 PX. Показаны кругом — именно так Telegram отображает аватар бота. Выбери понравившийся и нажми «Скачать».

Как поставить боту (1 минута):
1. Скачай понравившийся вариант кнопкой.
2. Открой в Telegram @BotFather.
3. Отправь команду /setuserpic.
4. Выбери своего бота MyCash из списка.
5. Отправь скачанный файл как фото.
Готово — новая иконка появится у бота.
