Как это работает

  • Сумма первой: на телефоне клавиатура откроется сама; в прототипе — экранный кейпад + «Далее»
  • Авто-переход: выбрал ответ — шаг сворачивается с галочкой ✓, открывается следующий
  • Видно всё: все шаги в списке, заполненные показывают значение — тапни, чтобы вернуться и изменить
  • Кошелёк: выбор из своих + «Создать новый» прямо в шаге
  • Тип — крупные цветные кнопки; Доп. параметры (направление/контрагент/дата) — необязательны, в самом низу
  • Сохранить активна, как только заполнено главное (сумма, кошелёк, тип, статья)
Если утверждаешь — встрою в приложение по шагам, чтобы ничего не сломать:
1. Шаги на реальных данных (кошельки/статьи/направления с сервера)
2. Автофокус суммы + цифровая клавиатура телефона на 1-м шаге
3. Логика «Перевод» (шаг 4 = «Куда» вместо статьи)
4. Сохранение через текущий saveQuickOp() — данные и сервер не трогаем
5. Тест на телефоне → правки → готово
Напиши «внедряй» — и начнём с шага 1.
