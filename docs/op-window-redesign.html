1. Apple Insetнативно

  • Тип: сегмент-контрол как в iOS — скользящий выбор, цвет по типу (красный/зелёный/синий)
  • Кошельки: чипы с цветной точкой банка, горизонтальный скролл
  • Статья: плитки, выбранная — синяя обводка
  • Направление/Контрагент: сгруппированный список со стрелками «›» (как Настройки iOS)
  • Кнопка: меняет текст под тип

2. Финтех + цвет-кодярко

  • Сумма: карточка-герой с градиентом по типу (расход — красный, доход — зелёный)
  • Тип: крупные кнопки с иконками ↓↑⇄ — понятно с первого взгляда
  • Блоки: каждый в своей белой карточке с мелким заголовком
  • Статья: плитки с эмодзи, выбранная подсвечена цветом типа
  • Фон: серый, карточки «парят» — глубина и порядок

3. Компактный смартбыстро

  • Сумма + тип в одной строке сверху — экономия места
  • Кошельки: круглые иконки-кнопки в ряд, выбранный «подсвечен»
  • Статья: чипы в перенос (flow) + «+ Новая» — всё видно сразу
  • Направление/Контрагент: две компактные строки рядом
  • Цель: заполнить операцию без прокрутки — максимально быстро
Напиши номер концепции — например «концепция 2».
Можно комбинировать: «сумма из 2, кошельки из 3, статьи из 1».
После выбора аккуратно применю к реальному окну (с твоим подтверждением на каждый блок).
